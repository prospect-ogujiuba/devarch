# DevArch implementation plans

Canonical, reviewable implementation plans live in this directory. Plans describe intended work and are not runtime configuration.

- [DevArch Home quality-of-life program](devarch-home-qol/00-program-index.md) — seven discovery-focused improvements with complete subphase plans, shared implementation contracts, dependencies, acceptance criteria, verification, rollout, and non-goals. ## Status convention

Each plan declares `Status: Planned`, `In progress`, `Blocked`, or `Complete`. Update the plan and its phase status when implementation begins or scope changes. Do not move canonical plans into `.model-artifacts/`.
