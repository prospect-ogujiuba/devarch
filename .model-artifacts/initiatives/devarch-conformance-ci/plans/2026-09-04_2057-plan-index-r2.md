## Incorporated specialist decisions

- Characterize existing checks before the absent-runner Red; each later contract starts with its own observable failing behavior and never claims plan-time Red.
- Keep direct test commands and Podman/Compose-provider behavior compatible; the new verifier and metadata are additive.
- Sanitize child environments, report keys rather than values, bound all logs/artifacts, use least CI permissions, and pin actions by SHA.
- Version strict local metadata, migrate category-by-category, manually review generated fields, and use expiring exceptions for structurally inapplicable health checks.
- Label and delete only run-owned rootless resources; use unique namespaces, bounded timeouts, unconditional idempotent teardown, and post-run leak gates.
- Split fast and runtime evidence while retaining complete dependency coverage; report `insufficient-sample` until 30 runs exist and measure failure-to-report latency.
