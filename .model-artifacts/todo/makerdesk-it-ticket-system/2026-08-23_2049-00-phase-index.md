# MakerDesk IT Ticket Management System Phase Index

Created: 2026-08-23
Purpose: Define the scaffold-first delivery order for MakerDesk without constructing MVC resources from scratch.

## Outcome

Deliver an application-owned IT ticket management system in `apps/playground/wp-content/plugins/playground-app`, using TypeRocket, MakerMaker, and the app Galaxy launcher wherever their generators or runtime commands apply.

## Constraints

- Every model/controller/fields/policy/registry vertical slice starts from `make:maker-resource` scaffolding.
- Prefer the most specific Galaxy context for writes: app launcher for application resources; MakerMaker/site launchers for discovery, validation, and commands they uniquely own.
- Generated migrations are reviewed before `migrate up`.
- MakerMaker and TypeRocket core repositories remain unmodified.
- Each phase stops at a directly verifiable boundary.

## Definition of done

- Core resources are traceable to generated scaffolds.
- Requesters and agents can complete the ticket lifecycle with explicit authorization.
- SLA, notification, audit, filtering, and reporting behavior is tested.
- Forward and rollback migration paths are verified.
- Operational commands and residual risks are documented.
