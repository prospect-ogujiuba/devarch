# Inventory API

Created: 2026-03-04
Purpose: Provide a safe localhost inventory boundary for the dashboard.

## Goal
Serve projects, running containers, and catalog services from the current DevArch checkout.

## Scope
- Python standard-library HTTP server bound to 127.0.0.1 by default.
- Scan `apps/*` and `services-library/*/*/compose.yml`.
- Read running containers using `podman ps --format json` without wrapping lifecycle operations.
- Initial API load and explicit refresh requests only; no polling.

## Outputs
- `scripts/dashboard/server.py`
- `scripts/dashboard/tests/test_server.py`

## Acceptance criteria
- Inventory output is deterministic and secret-safe.
- Missing Podman produces an available dashboard with a clear runtime error.
- API exposes one inventory response.
- Unit tests cover discovery and Podman parsing.

## Verification
Run the focused Python unittest suite.

## Non-goals
Lifecycle controls, metrics, logs, exec, authentication, remote access, and Compose parsing beyond discovery.
